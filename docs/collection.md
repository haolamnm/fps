# Collection

Path to collection will be fixed as `~/fps`.

Folder structure:
fps/
    videos/
        <video_id>.mp4
    resized-videos/
        tiny/
            <video_id>-tiny.mp4
        medium/
            <video_id>-medium.mp4
    selected-frames/
        <video_id>/
            <video_id>-<scene_id>.jpg
    thumbnails/
        <video_id>/
            <video_id>-<scene_id>.png
    config.yaml
    scenedetect.cfg
